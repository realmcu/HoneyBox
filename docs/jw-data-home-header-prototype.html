设计要点

  • 圆环语义切换：同步中紫色（#5C5CE0）+ 百分比或「等待计划」；完成后玫红（#FF2D55）+ 步数目标 %。
  • 固定高度：KPI 三列用淡入 + 顶部分割线，避免列表跳动；同步中收起 KPI，只保留环 + 文案 + 细进度条。
  • 主操作：整卡可点 = 同步；次要「历史同步详情」进 Hub；去掉右侧孤立「同步」按钮，减少抽象感。
  • 数据：Demo 层对当日 Activity 求和；目标步数暂 8000，后续接用户目标。
  • 失败：环归零或警示色，文案可点重试；保留上次成功 KPI 或灰显（产品可选，本原型为灰显 KPI）。
