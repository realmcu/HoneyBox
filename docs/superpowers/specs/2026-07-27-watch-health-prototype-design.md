# Watch 运动 / 健康原型设计

## 目标

为 Watch 模块设计“运动 / 健康”页面的可交互 HTML 原型。首版仅覆盖手表健康数据的同步与查看，不提供开始、暂停或结束运动等设备控制能力。

原型用于确认客户端的信息层级、状态反馈和响应式布局，不预先定义 BLE/L2 健康数据协议。

## 数据范围

首版展示四项核心指标：

- 步数
- 心率
- 睡眠
- 活动时长

页面必须明确区分真实数据、尚未同步和设备不支持，不能用看似真实的默认值掩盖缺失数据。原型正常状态中的数字仅作为布局样例。

## 页面结构

页面采用单页纵向滚动结构，延续 Watch 模块现有的蓝色 AppBar、浅灰背景和青绿色 Watch 强调色。

1. 顶部栏：返回按钮、标题“运动 / 健康”、同步按钮。
2. 同步状态：设备名称、最近同步时间、电量和当前同步反馈。
3. 今日概览：以紧凑的 2 x 2 指标网格展示步数、心率、睡眠和活动时长。
4. 趋势分析：提供“日 / 周 / 月”分段切换；步数使用柱状图，心率使用折线图。
5. 睡眠详情：展示总时长及深睡、浅睡、清醒的分布。
6. 最近记录：按时间排列最近心率与活动数据。

页面不使用嵌套卡片。各区块保持清晰但紧凑，适合移动端连续浏览，也能在 Windows 窗口中自然展示。

## 交互与状态

原型右侧控制面板可切换以下页面状态：

- 正常数据：展示完整样例数据和趋势。
- 未同步：指标与图表为空，主操作引导用户同步。
- 同步中：同步按钮显示进度并禁止重复触发。
- 同步失败：保留上次成功数据时标记数据时间；无缓存时显示空状态，并允许重试。
- 设备不支持：明确标记不支持的指标，不提供无效操作。

点击同步后，原型从“同步中”自动进入“正常数据”，并更新最近同步时间。日、周、月切换会更新图表标签与样例数据。

## 响应式布局

桌面浏览器中使用手机尺寸的主预览，并在右侧显示原型状态控制面板。窄屏时主页面铺满可用宽度，控制面板移动到页面上方或隐藏次要说明，确保文字、图表和按钮不重叠。

## 交付与验证

HTML 原型保存为 `docs/prototypes/watch-health-mockup.html` 并由 Git 管理。原型不依赖构建工具或网络资源，直接打开即可运行。

完成后使用真实浏览器检查桌面和移动端视口，验证：

- 页面无横向溢出或内容遮挡。
- 状态切换、同步和周期切换可操作。
- 图表在正常、空数据和不支持状态下表达清楚。
- 中文文本、图标和颜色在本地打开时正确显示。
